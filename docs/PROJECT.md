# PROJECT — ZAVEZEN_FIT

Премиальная система домашних тренировок для Telegram Mini App. Пользователь занимается сам, ориентируясь на понятную текстовую инструкцию, время, повторения и структуру тренировки. Визуального тренера, видео и голоса нет — это сознательное решение (DECISIONS D-001, D-002).

## Что внутри
Пять разделов: Главная, Тренировки, Упражнения, Прогресс, Профиль.
Ключевые функции: каталог с поиском и фильтрами; карточка упражнения (техника, целевые/второстепенные мышцы, исходное положение, частые ошибки); программы и собственные программы; экран тренировки (крупный таймер, подходы, отдых, пауза, переходы); история и статистика по неделям и месяцам; профиль и настройки; русский и украинский.

## Принципы
1. Тренировочная логика не зависит от интерфейса и проверяется тестами.
2. Время считается по фактически прошедшему (Date.now), а не по числу тиков, поэтому корректно после сворачивания Telegram.
3. Данные пользователя не теряются: защита от порчи, миграции, история без лимита.
4. Контент отделён от структуры и от языка; новые упражнения добавляются данными, без правок компонентов.
5. Никаких медицинских рекомендаций и обещаний результата; черновой контент помечен (D-008).
6. Статический frontend, бесплатный хостинг, минимум зависимостей.

## Стек
React + TypeScript + Vite; в рантайме только react и react-dom. Тесты: Vitest, Playwright. Хостинг: GitHub Pages (или аналог). Backend пока нет.

## Слои архитектуры
```
screens/ ─ ui/            интерфейс (React)
   │
app/                      роутер, провайдеры (i18n, доступ, Telegram)
   │
domain/                   чистая логика без DOM: engine, stats, catalog, рекомендации
   │
services/                 интерфейсы: Auth, Access, Content, Sync, Api  (сейчас локальные реализации)
storage/ platform/        localStorage-репозитории, Telegram, звук/вибрация
```
Правило зависимостей: domain ничего не знает о React и браузере; screens не обращаются к localStorage и Telegram напрямую, только через services/storage/platform.

## Готовность к Telegram и серверу (без переработки)
- Telegram Mini App API: вся интеграция в одном модуле `platform/telegram.ts`.
- Серверное хранение: репозитории за интерфейсом; записи имеют `id`, `updatedAt`, признак удаления; запись в хранилище проходит через хук (будущая очередь синхронизации).
- Доступ и Telegram Stars: интерфейс `AccessService`; интерфейс экрана спрашивает только «доступно ли», решение принимает сервер. Премиум-материалы, если появятся, должны отдаваться API после проверки (содержимое статического сайта публично).
- API: адрес из `VITE_API_URL`; если не задан — приложение работает автономно.
