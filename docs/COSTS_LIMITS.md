# Стоимость и лимиты (проверено 2026-11-18 по официальным страницам Cloudflare)

| Сервис | Назначение | Лимит Free | Ограничения | Возможные платежи | Когда появятся расходы |
|---|---|---|---|---|---|
| GitHub (репозиторий) | исходный код | бесплатно для публичного репозитория | — | — | приватный репозиторий с расширенными функциями — по тарифу GitHub (не проверялось) |
| GitHub Pages | сайт сейчас | бесплатно для публичного репозитория | лимиты Pages (не проверялись) | — | — |
| Cloudflare Pages | сайт после переезда | 500 сборок/мес, 20 000 файлов, 25 МиБ на файл, 100 проектов | 1 одновременная сборка, сборка ≤ 20 мин | платный план Pages | свыше 500 сборок в месяц |
| Cloudflare Workers | API | 100 000 запросов/день, 10 мс CPU на запрос, 128 МБ, 50 подзапросов | при превышении — ошибка 1027 до сброса в 00:00 UTC | Workers Paid | только если вы сами переключите тариф; на Free платить нельзя «случайно» |
| Cloudflare D1 | база | 5 млн прочитанных строк/день, 100 000 записанных строк/день, 5 ГБ всего, 10 баз | при превышении — ошибки до 00:00 UTC | только на Workers Paid | только после перехода на платный план |
| Google Identity Services | вход Google | бесплатно | настройка OAuth-экрана | — | — |
| Telegram Bot API / Mini App | бот, вход | бесплатно | — | Telegram Stars-платежи — комиссия при продаже (условия не проверялись) | при подключении оплаты |

Бесплатные лимиты не бесконечны: при росте нагрузки сервис на Free **остановит ответы**, а не начнёт списывать деньги, пока вы не включите платный план. Оценка нагрузки: вход ≈ 3–4 записи; синхронизация одного занятия ≈ 3–6 записей строк; 100 000 записей/день хватит на порядка тысяч занятий в день (расчёт прикидочный, не нагрузочный тест).
Не проверялось здесь: лимиты Workers Builds, GitHub Pages, цены Telegram Stars.
