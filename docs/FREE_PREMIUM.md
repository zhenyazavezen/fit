# Модель FREE / PREMIUM

| | FREE | PREMIUM (после подключения оплаты) |
|---|---|---|
| Упражнения (61) | все, с техникой, ошибками, вариантами | все |
| Программы | 9 из 17: B1, B2, B3, B4, I3, I6, R1, R2, R3 | все 17: + I1, I2, I4, I5, A1–A4 |
| Правила прогрессии и восстановления | полностью | полностью + автоподсказки «усложнить / держать / снизить» |
| Карта тела, профиль, подбор | да | да |
| История, избранное, свои программы | да, на устройстве | да |
| Аккаунт и синхронизация | да (пока без ограничений) | возможное преимущество — решает владелец |
| Экспорт данных | да | да |

**Почему так.** FREE даёт полноценный путь от нуля до уверенного среднего уровня и закрывает норму 2+ силовых занятий в неделю; Premium — скорость, автоматизация и расширенные программы. Безопасность (регрессии, стоп-сигналы) не продаётся. **I3 — бесплатная** (единственная силовая «всё тело» среднего уровня).

**Состояние.** Оплаты нет. Флаг `premiumEnforced` в `js/config.js` = `false`: программы Premium помечены, но открыты. Поле `accounts.premium_until` и `account.premium` в ответе `/me` готовы. Для включения нужно (отдельное решение): платёжная часть (Telegram Stars — условия не проверялись), миграция таблиц счетов, веб-хук бота, `premiumEnforced = true`. Блокировка на клиенте — не защита контента.
