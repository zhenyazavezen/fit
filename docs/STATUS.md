# STATUS — состояние проекта ZAVEZEN_FIT

Обновлено: 2026-11-19.

## Работает (проверено)
- Сайт: https://zhenyazavezen.github.io/fit/ (GitHub Pages, автопроверка: данные 61/17, 112 тестов, сборка).
- Каталог 61 упражнение, 17 программ, плеер с таймером, история, профиль, подбор по анкете и карта тела.
- Сервер Cloudflare Worker `fit` (https://fit.zavezenz.workers.dev) + база D1 `fit_db` (8 таблиц): `/health` отвечает, секрет `TELEGRAM_BOT_TOKEN` задан как Secret.

- Обновление репозитория с телефона: `incoming/update.zip` + `apply-update.yml` (см. README).

## Не сделано / ограничения
- Вход через Google: код есть, Client ID не создан (`docs/GOOGLE_OAUTH.md`).
- Оплата и серверная защита Premium не подключены (`premiumEnforced:false`); все программы сейчас открыты.
- Синхронизация проверена на одном устройстве; проверка на двух устройствах и объединение аккаунтов — руками.
- Тексты упражнений и программ — `review: draft`, нужна проверка тренером/кинезиологом.
- Украинского языка нет; шрифт системный; иллюстрация-карточка только у приседаний; B4/I5 — подходами, не кругами.
- Префикс локального хранилища `seven:` оставлен намеренно (смена префикса потеряла бы данные пользователей без миграции).
- Сквозные тесты (Playwright) запускаются отдельным workflow `e2e.yml`, а не блокируют публикацию.
