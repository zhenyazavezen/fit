# Telegram Mini App: настройка и проверка

- Mini App должен открываться через бота (меню-кнопка или Main Mini App в @BotFather → Bot Settings → Menu Button / Configure Mini App → URL `https://zhenyazavezen.github.io/fit/`). Только так Telegram передаёт `initData` с подписью. Запуск из обычной клавиатурной кнопки `initData` не даёт — вход через Telegram там невозможен.
- Токен бота — только в secret `TELEGRAM_BOT_TOKEN` Worker.
- Сервер принимает `initData` не старше 24 часов; будущее время и неверную подпись отклоняет.
- Вход не навязывается: кнопка «Продолжить через Telegram» в разделе «Аккаунт» (профиль → Аккаунт).

## Проверка вручную (после развёртывания)
1. Откройте Mini App из бота → Профиль → Аккаунт → «Продолжить через Telegram» → должно появиться «Вы вошли».
2. Выполните тренировку, нажмите «Синхронизировать сейчас» → статус «Данные синхронизированы».
3. Откройте то же из браузера, войдите через Google, привяжите по коду → история на обоих устройствах одна.
